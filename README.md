# Hesy releases

Signed builds of [Hesy](https://hesy.app), the dictation app that cleans your speech as you talk.

Download from [hesy.app](https://hesy.app) or the [latest release](https://github.com/hacksurvivor/hesy-releases/releases/latest).
The macOS app is signed and notarized; every update is checked against the app's built-in signing key before it installs.
